## Complete boundary and preserved formats

The owning config/compile module combines existing pure D38/D39/D40 policy types,
reference/private/resource checks and D41 catalog encoding. Policy stays independent
of config/core; no new registry dependency, feature, lockfile, signed schema field,
network operation or cryptographic implementation. Action enums are copied values;
canonical name/matcher copies are explicit bounded owned table entries after the
complete expansion preflight, never a borrow-checker workaround or shared mutable cache.

CompletePublication accepts actual resource bytes and real VerifiedCatalogRevision
objects. Every catalog resource must equal its independently imported/approved
object; a JSON approval claim or standalone D39 facts cannot substitute. It owns
canonical SnapshotContent and its matching compiled tables; its signing method is
the complete CP publication path. The existing low-level D11 codec stays a primitive,
not publication authority. Existing codec/golden bytes and original spelling remain.

DP public compile entry points belong only to VerifiedSnapshot/RestoredSnapshot.
Actual complete resource count/64MiB budget and hashes/exact pin set are checked
before catalog buffering. A shared D41 streaming scan checks ALL catalog raw array
entries/depth first. The private resource-v1 decoder checks exact kind/identity,
canonical ASCII/modes/order/hash spelling/metadata/evidence/strict shape, and compares
bounded reserialization with the actual bytes. DP source hashes are CP-attested
provenance, not independently rehashed absent raw sources or feed license approval.
Standard TryFrom preserves catalog-vs-device/upstream/secret identity kinds without
adding a direct policy dependency to core.

One checked10000 prepared-entry budget includes Profiles, independent Endpoint/group
associations, expanded DNS/TCP/port rules, private records, legacy/gateway scopes and
expanded target/port/outbound entries, including disabled declarations. It runs
before multiplying/copying conditions. Every supplied catalog closure/current pin
and selected revision is validated; complete compiled policies pass D39 reachable
conflict validation. Service dependencies only validate, never inherit conditions
or actions. Filters independently compile DNS Block and TCP Deny in each selected
Profile; priorities/ports/stable sources keep D38 semantics.

Private RRsets are canonical Profile-local data without a newly chosen response
precedence/RCODE. Gateway scope tables preserve exact grant/group/listener/source,
explicit/service-own targets, ports and outbounds. Their pure match does not grant
live access or checked addresses. Availability is never persisted as permission;
native declarations remain references and D40 current request-time facts/refusal
semantics continue. Actual ingress, revocation, freshness, TLS, DNS responses and
SSRF/address pinning remain P3/P4.

Core Generation fresh/restore compiles before construction, staging or commit.
Decision borrows both consumers' tables from that single pinned Generation.
Failed candidates preserve the old compiled view and floor; successful replacement
does not mutate held old decisions. Reopen reconstructs tables from authenticated
retained resources without CP/database. D36 corruption/revocation/rollback rules
and filesystem state machine are preserved; no old-slot fallback is introduced.
